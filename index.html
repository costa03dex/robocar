Publicar no GitHub Pages (Grátis)

Coloque seu robô no ar para acessar no celular ou computador!

1

Crie um Repositório no GitHub:

Acesse github.com/new, escolha o nome bobi-assistente e marque como **Público**.

2

Adicione o arquivo index.html:

Clique em "Creating a new file", nomeie como index.html e cole o código completo.

3

Ative o GitHub Pages:

Vá em **Settings > Pages** no repositório. Em **Source**, selecione o branch main e clique em Save.

4

Pronto! Seu robô no ar:

Acesse de qualquer dispositivo no link:
https://seu-usuario.github.io/bobi-assistente/
